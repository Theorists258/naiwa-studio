# Windows 便携版使用说明

适用于 **Windows 10 / 11 x64**。便携包名为 `Naiwa-Studio-v0.1.0-windows-x64.zip`，无需安装 Node.js 或 Python。

## 第一次打开

1. 将 ZIP **完整解压**到一个文件夹，例如“文档”中的奶蛙 Studio 文件夹。
2. 打开解压后的文件夹，双击 `奶蛙Studio.exe`。
3. 小控制窗启动后，默认浏览器会打开 [奶蛙 Studio](http://127.0.0.1:4178)。点击播放或试听即可开始。

请在解压后运行，不要直接在压缩包里双击 EXE。`奶蛙Studio.exe` 与 `www` 文件夹需要放在一起；移动软件时，请移动整个文件夹。

解压后的便携版可在断网时使用。界面在本机浏览器中运行，内置声音随包提供；导入音频、录制步点、打开工程和导出 WAV 的操作与 [项目说明](../README.md) 相同。

## 保持运行与退出

使用期间保留小控制窗。关闭浏览器页面后，启动器仍会运行，可点击控制窗的浏览器按钮重新打开，也可手动访问 [http://127.0.0.1:4178](http://127.0.0.1:4178)。

结束使用时，先在网页中保存作品，再点击控制窗的退出按钮或关闭控制窗。**关闭控制窗会停止本地服务**；下次使用时重新双击 `奶蛙Studio.exe`。

## 保存、备份与迁移

网页中的“已自动保存”表示作品存入了当前浏览器的本地存储，并不表示作品保存在便携软件文件夹中。自动保存与浏览器、浏览器用户配置及本地地址有关；换浏览器、使用无痕窗口、清除网站数据或换电脑，都可能无法看到原来的自动保存。

- **备份工程**：点击网页中的“保存”，下载 `.naiwa.json` 文件。它包含编曲参数和用户导入的音频，建议另存到自己的作品文件夹。
- **继续编辑**：点击网页中的文件夹按钮，选择备份的 `.naiwa.json`。打开工程会替换当前作品，请先保存当前需要保留的内容。
- **分享成品**：点击“导出 WAV”。WAV 包含 4 次循环和尾音，用于收听；继续编辑需要保留 JSON 工程。
- **更换电脑或更新软件**：先下载工程备份，再在新的便携版中打开。仅复制软件文件夹不会复制浏览器的自动保存。

浏览器下载的文件保存在其设置的下载位置。若导入较大音频导致自动保存失败，请及时下载工程文件备份。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 浏览器没有自动打开 | 确认控制窗仍在运行，使用其浏览器按钮，或手动打开 `http://127.0.0.1:4178` |
| 浏览器提示无法连接 | 检查控制窗是否已退出，重新启动 `奶蛙Studio.exe`；若控制窗显示错误，按错误信息处理 |
| 提示端口占用或已有服务 | 先关闭之前启动的奶蛙 Studio 控制窗，再启动一次；如果仍提示占用，退出占用端口 4178 的其他应用后重试 |
| 提示找不到网页文件 | 完整重新解压，确认 EXE 旁边有 `www` 文件夹，且未单独移动 EXE |
| 页面打开但没有声音 | 点击播放或试听，检查浏览器标签页是否静音、系统输出设备和音量；确认所选轨道没有被静音 |
| 导入音频失败 | 使用浏览器支持的音频文件；单文件不超过 15 MiB、120 秒，合计导入容量约 30 MiB（按 Base64 体积估算） |
| 自动保存的作品不见了 | 使用原来的浏览器及用户配置打开同一地址，或通过文件夹按钮载入之前下载的 JSON 备份 |
| Windows 或安全软件阻止启动 | 先核对软件来源和提示内容；不要关闭系统防护。如果仍无法启动，请保留完整提示，向维护者反馈 |

反馈问题时，请说明 Windows 版本、使用的浏览器、操作步骤和控制窗或浏览器显示的错误。不要在公开反馈中附带自己的私密录音或工程。
